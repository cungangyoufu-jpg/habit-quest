# Habit Quest

勤務区分(勤務・非番・公休)に合わせて使える、ゲーム風の習慣トラッカーです。

- 習慣のチェック、連続日数、レベル、実績バッジ
- 勤務サイクルのカレンダー(日ごとの変更も可能)
- スマホ使用時間の記録とグラフ
- 食費の記録、月の予算、円グラフ
- データはすべて端末内(ブラウザの localStorage)に保存され、サーバーには送信されません

## スマホで使う

1. スマホで公開URLを開く
2. iPhone: Safari の共有ボタン →「ホーム画面に追加」 / Android: Chrome のメニュー →「ホーム画面に追加」

※ データは端末ごとに別々です。機種変更や別端末へは、設定画面の「書き出し/読み込み」で移せます。

## パソコンで動かす

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 更新するとき

`index.html` などを変えたら、`sw.js` の `VERSION` の数字を上げてください(スマホ側のキャッシュが入れ替わります)。
